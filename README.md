# cliproxy-plugins

Third-party plugin registry for [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI).

## Usage

Add to your CPA `config.yaml`:

```yaml
plugins:
  store-sources:
    - "https://raw.githubusercontent.com/nguyenha935/cliproxy-plugins/main/registry.json"
```

Then open the Plugin Store UI and install any listed plugin.
